## 优化必须保持的条件

- 唯一硬件 owner、SDK 完成复位、同帧归属、过期拒绝、帧校验、有限缓冲、输出比较与硬件故障隔离不删减。
- 不因 CPU 总均值较低就排除单线程、DMA、DDR/AXI、VPU 缓冲或同步问题；没有硬件计数器时明确标“未测”。
- 语音服务运行期间只做不争用设备的检查；不停止其他任务，不因隔离标记妨碍重试就删除它。
- 代码编译、模拟测试、离线解码、浏览器播放、现场推理、长稳和时序签核分别列结果。冻结功能不等于取消缺陷修复，也不等于宣布所有既定指标完成。
- 正式切换前保留完整回退材料；无法证明 SDK 正常关闭时按已有隔离流程处理，不在同一故障启动继续试开设备。回退不删除新增 MP4 或人员资料。

## 可复跑的软件检查

不访问模型设备的 Windows 测试可使用现有隔离依赖。先确认下列路径存在；不要因此安装依赖到共享 SDK 或把缺依赖算测试通过。

```powershell
Set-Location D:/renlianshibie/fpga_project
$env:PYTHONPATH='D:/renlianshibie/fpga_project;D:/renlianshibie/fpga_project/lan_stream;D:/renlianshibie/fpga_project/npu_photo;D:/yzd/tmp/face-pl-20261015/opencv410;D:/yzd/tmp/face-pl-20261015/python'
$env:PYTHONDONTWRITEBYTECODE='1'
# 各文件独立进程，避免模拟模块相互影响；任何非零退出都要记录。
Get-ChildItem tests/test_*.py | ForEach-Object {
    python $_.FullName
    if ($LASTEXITCODE -ne 0) { throw "测试失败：$($_.Name)" }
}
foreach ($name in @('test_sdi_diagnostics.py','test_vpu_live_server.py','test_h264_fragments.py','test_external_h264.py','test_device_status.py')) {
    python "lan_stream/$name"
    if ($LASTEXITCODE -ne 0) { throw "测试失败：$name" }
}
Get-ChildItem tests/test_*.cjs | ForEach-Object {
    node $_.FullName
    if ($LASTEXITCODE -ne 0) { throw "测试失败：$($_.Name)" }
}
# 为本次执行选择新的独立证据目录，不覆盖已有验收收据。
python lan_stream/test_raw_stream.py --out D:/yzd/tmp/acceptance-rerun/raw-protocol.json
if ($LASTEXITCODE -ne 0) { throw '原始帧 HTTP 测试失败' }
```

Windows 的 3 项平台跳过必须另在 Linux 隔离副本运行：`tests/test_owner_pad.py`、`lan_stream/test_external_h264.py`。复制依赖闭包，设置独立临时目录及单线程计算环境；这些测试模拟硬件，不需要启动/停止正式服务。不要直接执行 `serve_photos.py`、历史部署脚本或旧摄像头例程来代替测试。
