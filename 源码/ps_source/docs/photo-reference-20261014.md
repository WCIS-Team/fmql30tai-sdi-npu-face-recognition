## 已实现的路径

公开照片文件 → SCRFD 人脸框与五点 → 112×112 五点对齐 →
MobileFaceNet 512 维特征 → L2 归一化 → 本地测试身份库余弦比对 →
姓名/未知 → 网页显示该照片的原图、框、五点、对齐裁图和分数。

后端为本机 WSL Ubuntu 的 ONNX Runtime CPU；C++17 核心从旧工程复制到
`photo_reference/`，独立构建。原源码和模型复制校验见该目录
`migration-manifest.json`。未改旧工程、case RTL、板卡固件或 SDK 采集通路。

## 证据边界

11张公开照片涉及5个身份，其中登记2个；4张未知照片属于3个未登记身份。
正向校准只有样本A，没有覆盖样本B。公众人物照片不代表真实校园摄像头，
没有进行总体准确率、活体检测、持续性能或门禁验收。
本次通过不代表 YuNet / iCraft 量化后的模型通过，更不代表 NPU 或 PL 验收。
当前下一步应固定目标模型和输入合同，再做照片文件输入的板端适配与数值对照。
