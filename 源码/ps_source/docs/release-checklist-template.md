# 应用发布记录模板

复制到新的任务目录填写，空项表示尚未完成；不预填 passed=true。实施日期按 Asia/Shanghai，跨日分别记录。只适用于 [发布与回退说明](release-runbook.md) 的现役 540p 范围。

## 身份与变更

- 日期/任务目录/操作人：
- 现场 boot_id、owner PID/session、其他运行任务：
- 原 app / 候选 app / 独立录像 app：
- 主配置、启动配置、三个服务、真实 --site、模型/PAD及数据路径：
- 改动目的、逐文件旧/新 SHA256、源码映射、明确未改的依赖：
- 构建收据和源码包（如有）、软件回归结果与失败日志：

## 备份与停机

- 完整服务/配置备份目录及校验：
- 旧应用校验、人员库和已有录像清单；动态回执单列：
- 录像收尾状态，停止顺序及时间：
- 本次 owner 关闭回执路径、sdk_closed / camera_pending / exit_code：
- 隔离标记的 boot_id 与本次启动的关系：

## 切换与验收

- 配置组写入、主/启动 app 一致、daemon-reload：
- 候选源文件/程序/服务散列检查：
- 就绪等待结果；三个服务、帧推进、录像输入：
- 固定输入数量、检测/身份/PAD原始输出比较与张量位置：
- 现场样本条件、同帧归属、浏览器播放证据：
- 新录像 ID、帧数、全解码、索引、Range、旧格式检查：
- 数据完整性差异及解释（原文件、外部新增、本次新增分别记）：
- 性能采样时长/负载、CPU范围、内存、帧率、错误与日志：
- 重启/长稳：未做或写明具体证据，不使用其他阶段代替：

## 结果与恢复

- 最终状态：未执行 / 中止 / 已回退 / 有限验收通过；依据：
- 每次失败的独立结果与原始日志：
- 若回退：配置恢复、安全关闭证据、旧版健康与播放分别记录：
- 最终 verification 指向、录像模式、其他任务前后身份：
- 未完成事项和验证限制：
- 关键本地来源文件：
- 同步归档 `D:/bigfuture/竞赛/记录/YYYY-MM-DD.md` 的位置和检查结果：
