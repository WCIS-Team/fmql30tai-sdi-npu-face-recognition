## 修复过的工程问题

- 厂商 `frame_ctrl` 注释包含 GBK 字节，补丁工具按 UTF-8／GB18030 检测读取，在副本中统一为 UTF-8。
- 原 XPR 引用两个不存在的 place hooks，准备脚本删除失效引用，重新按教程加载已有 JFM hooks；没有发明空脚本掩盖依赖。
- 原 `impl_constraints.xdc` 两行把 `##` 放在 `set_property` 参数末尾，Vivado 报 `Invalid option value '##'`，后续约束因此未执行。副本改成 `; #`，不改变 PACKAGE_PIN 或电平值。
- 项目携带 PS 自定义 IP 与工具内建同名 IP，Vivado 报重复，使用副本里的厂商 PS IP；没有自动升级或替换成普通 Zynq PS。
- 新增帧率配置使用 held payload＋request／ACK，解决这个新控制字段的原子传递；**不把旧 crop/stride 寄存器的 CDC 一并宣称修复**。

本次最终全工程展开的主要关键告警来自原 `ai7030.xdc` 对 `REQP-44/46/52/56` 降级，已在 README 明确保留给硬件兼容审核；最终运行日志记录实际数量。原源码还包含 ANSI 端口重声明、宽度匹配、FIFO/CDC 等告警，未对不在本轮修改范围的厂商核心进行批量“清警告”。
