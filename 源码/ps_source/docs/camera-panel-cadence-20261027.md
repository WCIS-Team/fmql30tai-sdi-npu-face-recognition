# 检测小窗请求间隔与单次检测复用（2026-10-27）

用户反馈后端处理约 0.6 秒，但检测小窗一秒多才更新。重新核对正式网页与本地源码一致：成功后额外等待至少 750 毫秒并加 0～500 毫秒随机错峰；较长请求还会按处理耗时延长间隔。“检测一次”原先先暂停、等待已有请求完成，再发起新请求，因此可能连续等待两轮。

## 实现

- `npu_photo/camera_panel.js`：成功后的下一次请求间隔固定为 50 毫秒，上一请求和图片加载结束后才调度，不建立请求队列。409/429 仍指数退避并随机错峰，上限 4.5 秒；暂停、隐藏页面及证据过期检查保留。
- “检测一次”停止自动循环并接管本页正在进行的检测，使用该请求原本对应的照片和结果，不丢弃结果后重新推理。连续点击共享同一请求；后续显式暂停或隐藏页面仍使在途结果失效。无在途请求时只发起一次。
- 正式站点 `index.html` 将脚本版本更新为 `20261027-fast-1`，使刷新页面加载新代码。未改模型、位流、人员库、后端计时或录像模式，没有通过省略防伪提速。
