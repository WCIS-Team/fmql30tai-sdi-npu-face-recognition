| 指标 | 切换前 | 切换后 |
|---|---:|---:|
| 六进程 CPU 合计，核 | 0.550 | 0.506 |
| owner，核 | 0.339 | 0.322 |
| 照片服务/媒体观察器，核 | 0.058 | 0.044 |
