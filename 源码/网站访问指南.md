# 网站访问步骤

环境　板卡已按板端安装说明部署程序；板卡和电脑接入同一个可互通的局域网；使用浏览器通过 HTTP 访问。

## 1. 连接并启动板卡

接好 SDI 摄像头和板卡网线，板卡上电。电脑接入同一路由器的有线网络或 Wi-Fi。先按 [板端安装说明](board_runtime/README.md) 完成首次安装，只有官方 Linux 或只替换 BOOT.bin 不会自动安装我们的网页程序。

## 2. 确认板卡 IP

在板端终端执行：

```sh
ip -4 addr show eth0
```

查看 `inet` 后的地址。当前板卡地址是 `192.168.1.113`；换网络或 DHCP 分配变化后，以实际地址为准。

## 3. 在手机或电脑浏览器打开网站

把完整地址输入电脑浏览器地址栏：

| 页面 | 当前板卡地址 | 用途 |
|---|---|---|
| 主站 | http://192.168.1.113:8091/ | 底部切换直播、录像、数据库（人员登记） |
| 实时预览 | http://192.168.1.113:8092/ | 单独查看实时视频 |
| 录像页面 | http://192.168.1.113:8093/ | 设置录像模式、查看及回放录像 |

使用 `http://`，保留端口号。直接连接板卡时填写板卡 IP；下文的电脑摄像头入口才使用 `localhost`，它指向运行入口程序的电脑。板卡 IP 变化时只需替换网址中的 IP。

主站应出现实时画面，镜头对准现场后画面应持续变化。人员库初始为空，先在主站登记人员照片，才能测试已有人员识别。录像服务启动不代表正在录制；在录像页面按需要选择模式，录完后检查列表与回放。

## 4. 设置以后开机自动启动

首次部署时，在板端终端执行：

```sh
systemctl enable wcis-face-photo.service wcis-sdi-vpu-view.service wcis-face-recording.service
```

人员库挂载服务由主站的依赖关系自动启动。当前部署的三个网页服务已经启用开机启动，无需每次手动执行。

## 5. 页面打不开或没有画面时检查

以下命令在板端终端运行：

```sh
systemctl is-active wcis-face-photo.service wcis-sdi-vpu-view.service wcis-face-recording.service
curl --fail http://127.0.0.1:8091/api/health
curl --fail http://127.0.0.1:8091/api/camera/status
```

正常时三个服务显示 `active`，健康接口的 `status` 为 `ready`，`model_cache_ready` 和 `hardware_admission_ready` 为 `true`；相机接口 `ready` 为 `true`。隔几秒再查一次，相同会话的 `frame_id` 应增加。

- **完全打不开网页：** 先确认 IP、端口和局域网连通，再检查服务是否启动。若板端本机访问正常而电脑打不开，应检查电脑与板卡之间的网络。程序更新后页面异常，可用 Ctrl+F5 强制刷新。
- **网页能打开但没有画面：** 打开页面只证明网页服务正常。若相机接口返回 503，检查摄像头连接及下面的错误记录：

  ```sh
  journalctl -u wcis-face-photo.service -n 60 --no-pager
  cat /root/wcis-face/hardware-review-required.json
  ```

  若当前启动的故障为 `capture_dma`，采集已进入保护状态，仅刷新网页或重启网页服务不能解除。不要直接删除保护标记强行重试。先保存日志、确认录像已停止且板上其他任务可以中断，再正常重启：

  ```sh
  sync
  systemctl reboot
  ```

  重新连接后重复本节的健康和帧号检查。若故障再次出现，继续保留日志排查；重启恢复不等于找到了根因。

2026-11-04 本板发生过采集 DMA 故障，网页返回 200，但相机接口返回 503。经正常重启，主站、模型缓存及相机恢复就绪；此操作没有更换 BOOT 或删除人员库、录像。

## 人员登记与照片识别

底部三个入口分别为 **直播 / 录像 / 数据库**。数据库用于登记和管理人员；历史样本列表已移除，已有人员资料保留。

### 手机拍照登记

手机与板卡接入可互通的网络，打开 `http://192.168.1.113:8091/#database`。填写姓名，点击“手机系统拍照”，使用手机摄像头拍摄清晰单人照片。也可以点击“相册 / 文件上传”。检查预览，可移除不合适的照片，然后点击“确认登记”。手机系统或浏览器可能改为显示图片选择；此时可以先用系统相机拍摄，再从相册选取。

### 电脑摄像头登记

电脑安装 Python 3 后，双击本包根目录的 `启动电脑摄像头登记.cmd`，保持窗口运行，再打开 **http://localhost:18091/#database**。点击“打开设备摄像头”，允许浏览器使用摄像头，点击“拍一张”，核对姓名和预览后“确认登记”。摄像头是这台电脑连接的设备。

当前入口默认连接板卡 `192.168.1.113`。板卡 IP 改变时，在包根目录终端运行：

```powershell
python -B .\ps_source\scripts\serve_desktop_site.py --board-host 新板卡IP
```

入口只在本机监听，不会自动安装或开机启动。电脑重启或关闭入口后需重新启动；端口已被占用时先检查是否已有入口在运行，不要重复启动。`localhost` 入口须在使用摄像头的那台电脑运行；手机不应填写此电脑入口。

普通局域网 HTTP 页面不能直接启用浏览器 getUserMedia；HTTPS 或 localhost 才满足安全上下文要求，因此提供本机入口。依据：[MDN](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)。不需要关闭浏览器安全检查。

### 其他操作

- 照片确认前只保留在页面中；关闭或刷新页面会丢失尚未提交的照片。离开数据库页会关闭设备摄像头。
- 一次可准备多张照片；成功的照片从待登记列表移除，失败的保留供重试。同名登记追加特征，每人最多 30 份。
- 已登记人员支持姓名搜索、补充照片和确认删除。删除后按实际服务策略移除资料；谨慎确认。
- “用照片测试识别”折叠区只展示本次上传结果，不会自动登记。
- 登记服务异常可点击“刷新人员库”；程序更新后仍见旧内容，可按 Ctrl+F5 强制刷新。
